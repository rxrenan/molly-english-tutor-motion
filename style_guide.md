# style guide - tutora de inglês (teste)
- sistema: Deep Field v2.2. fundo void #08090B, superfícies deep #0E0F12 / hull #17191D, linhas #24272D, texto starlight #F1F3F6, secundário titanium #B8BEC7 / steel #858B95.
- acento único: lavanda #A99BE6 (cor do avatar GrokBot e do fundo da Molly). sem glow em ui.
- tipografia: Geist (títulos 64-84px, 500, tracking -0.02em), Geist Mono (rótulos 26-30px). tudo lowercase pt-BR, sem travessão.
- texto alinhado à esquerda na margem 96px, nunca título centralizado com gradiente.
- container único: o telefone (moldura #000, raio 88) atravessa o vídeo; só ele se transforma (x, y, escala, rotação) com molas empilhadas.
- ui real dentro do telefone em modo claro (branco, bolhas pretas), recriada em código a partir dos prints.
- personagens: GrokBot (avatar oficial + grokbot_ready_cut) como ajudante que carrega as transcrições; Chatot (frame do gif) como professor. ElevenLabs só como wordmark de texto.
- movimento: spring fechada por mudança de alvo, entradas por deslocamento/escala/máscara, nunca tudo em fade. algo novo a cada 2-4s.
- rodapé fixo: logomark + renan rosa + linkedin.com/in/renanrrosa (copiado de outro projeto do portfólio).
